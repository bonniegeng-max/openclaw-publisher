# 作品集决策示例

## 输入快照

| Skill | 发布时长 | Downloads | Installs | 搜索状态 |
|---|---:|---:|---:|---|
| A | 35 天 | 120 | 18 | 核心关键词前列 |
| B | 20 天 | 80 | 0 | 可搜索但摘要模糊 |
| C | 2 天 | 5 | 0 | 已上架 |
| D | 60 天 | 3 | 0 | 同类强者很多 |

## 错误结论

- A、B 下载都高，所以都继续加功能
- C 只有 0 installs，所以失败
- D 继续发版本，期待自然起量

## 证据型结论

### A：加码

- 已形成安装信号
- 搜索词和定位一致
- 适合补真实案例和系列入口

### B：修复

- 有下载但没有安装
- 先排查摘要、目标用户、依赖门槛和安装说明

### C：观察

- 发布不足 7 天
- 只验证可见、clean、可安装，不做停更判断

### D：停更或重定位

- 观察期充分
- 搜索竞争成熟
- 自身没有明显差异

## 下一步

只选一个最高价值动作，例如：先修 B 的首页摘要与安装门槛，然后观察 7 天，不同时改四个 skill。
