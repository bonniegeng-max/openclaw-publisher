## 修复后验收

- [ ] 目录名与稳定 slug 一致
- [ ] 人类可读 `name` 与页面标题一致
- [ ] 本地版本高于 registry latest
- [ ] dry-run 返回预期 slug、展示名和版本
- [ ] 示例、依赖和环境声明没有冲突
- [ ] 正式发布后再用 `inspect` 与隔离安装证明 E4
