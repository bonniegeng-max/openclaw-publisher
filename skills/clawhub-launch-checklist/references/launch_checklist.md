# 发布前检查清单

## 1. 基础结构

- `SKILL.md` 存在
- frontmatter 可解析
- `name`、目录名、标题没有明显冲突
- `version` 已声明

## 2. 页面首屏

- 第一段能说明解决什么问题
- 摘要没有写成功能列表
- 目标用户不是“所有开发者”
- 前三段长度可读，不像大段说明书

## 3. 发现性

- `categories` 已配置
- `topics` 已配置
- 至少有一个真实示例或真实失败场景
- 页面里存在一句能被记住的差异点

## 4. 信任感

- 没有把 token 或敏感信息写死在示例里
- 有 changelog 或其他证明它不是一次性草稿的文件
- 说明没有夸大能力

## 5. 发布动作

- 已计划执行 `clawhub skill publish <path> --dry-run --owner <owner>`
- 这次发布的目标是“值得上线”，不只是“命令能过”
