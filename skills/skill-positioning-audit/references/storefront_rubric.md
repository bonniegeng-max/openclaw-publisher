# 商店页评分规则

## 评分维度

总分 25 分，每项 0 到 5 分。

### 1. 标题清晰度

- 能否在第一眼说明它是做什么的
- 是否像产品，而不是像内部目录名

### 2. 摘要转化力

- 是否先讲结果，而不是先讲过程
- 是否够短，够具体

### 3. 目标用户聚焦度

- 是否能一句话说明给谁用
- 是否避免“谁都能用”的模糊写法

### 4. 差异化记忆点

- 是否存在一条别人能记住的独特判断
- 是否能和同类 skill 快速区分

### 5. 信任感

- 是否有真实案例、真实输入输出或真实失败场景
- 是否让人感觉作者真的做过这类问题

## 分数解释

- `0-10`：模板感强，不建议直接发布
- `11-17`：能发，但转化会比较弱
- `18-21`：已有明显产品感
- `22-25`：定位清晰，值得重点打磨
