# 摘要对比示例

## 弱摘要 1

`帮助开发者更高效地完成各种任务。`

问题：

- 完全不知道是什么任务
- 谁都能套用
- 看不出为什么现在要装

更强版本：

`在发布到 ClawHub 前，帮你把 skill 摘要改得更短、更清楚、更像产品文案。`

## 弱摘要 2

`一个用于检查、优化、分析和改进 skill 页面表现的工具。`

问题：

- 动词很多，但没有结果
- 读起来像功能列表
- 没有明确用户

更强版本：

`把模糊、冗长、像模板的 skill 摘要，改成更容易被理解和被安装的商店页文案。`

## 弱摘要 3

`适合所有开发者使用的摘要优化助手。`

问题：

- 目标用户过宽
- “优化助手”没有记忆点

更强版本：

`给准备把 skill 发布到 ClawHub 的开发者，用来快速重写首页摘要的专用工具。`
